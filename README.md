# Rialto Cables homepage

Static homepage with its required stylesheets, JavaScript, and images. `index.html` is at the repository root.

## Deploy on Vercel

1. Import `Sanjay1820/rialto-cable-1` as a new Vercel project.
2. Select the `main` branch and leave Root Directory as `./`.
3. Use Framework Preset **Other**. No install or build command is needed; Output Directory is `.`. These settings are included in `vercel.json`.
4. Deploy.

This repository includes only the homepage. Links to About, Contact, product pages, and other HTML pages require those pages to be added before they can work on this deployment.

External Google Fonts and Font Awesome resources require an internet connection.
